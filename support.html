Help with your private workspace

This public site provides information and a route to the existing private CaseVac Ai app. It does not create an account, accept claim evidence or grant access to private records.

Open the existing private app

Use the ChatGPT account that owns CaseVac Ai to sign in. Google permission is a separate step used by its manual two-document reader.

Open private CaseVac Ai

The app currently permits its existing owner only. This link does not make the app or its records public.

Check a Google Drive connection

  1. Open the connection panel. Select Connect Google Drive in private CaseVac Ai. Use the Google account that can open the configured project documents.
  2. Review the permission. The current reader requests read-only Drive access. Google consent and a successful document read are separate steps.
  3. Check each source result. Use Refresh sources when connected. Confirm that each of the two documents reports a successful read and a source-read time. Older information can remain visible when a refresh fails.
  4. If a read fails, open Read details. Note the displayed error category, whether it concerns document details or export, and any HTTP status. Do not repeatedly change clients, permissions or account settings without identifying the cause.

Browser tokens last only for the open page session. Reloading can require another connection. Use Disconnect this session to clear the reader state; use your Google Account connections to revoke Google's permission.

Contact support

Email lsutigerscc14@gmail.com for non-sensitive support or privacy questions.

Include the page you were using, your browser/device, the approximate time and the displayed error category. Keep passwords, authorization codes, access tokens, claim numbers, medical records and complete evidence packets out of the first email. If a screenshot would reveal private information, describe the problem instead.

Do not post private information in public GitHub issues. The public website repository is for this informational site's updates; it is not an evidence inbox.

What this website does not provide

The existing VA Desk, Command Center, dashboard and scanner belong to the same CaseVac Ai project. This public site does not connect the dashboard, start background scanning, upload PDFs or Word files, or run an automatic evidence evaluation. The private ChatGPT MCP connection is published, and its status tool has responded successfully. It reports dated synced copies rather than live Drive data on every request. Check the reported sync time and source coverage; a working connection does not establish that every tool or document has been tested.

CaseVac Ai does not access your VA account, submit a claim, sign a filing or establish entitlement. For official claim submission or account services, use the appropriate official VA channel.

Read the privacy notice for current data handling and retention limits.
