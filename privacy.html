Privacy policy

Last updated: November 5, 2026

About this site

This GitHub Pages website publishes information about VAAP. It is separate from the private VAAP application and does not provide access to veterans' records.

Information you submit

This website does not contain account registration, record upload, or contact forms. Do not post sensitive personal, medical, or benefits information in public GitHub issues.

Hosting and technical data

GitHub hosts this website and may process technical information such as IP addresses and request logs according to its own policies. See GitHub's privacy statement.

Private application

The private VAAP application's data access, OAuth permissions, retention, and deletion practices require separate documentation and review before its integration is made available. This public-site policy does not describe or authorize those private data flows.

Changes and questions

This page will be updated when the site's features or data practices change. For non-sensitive questions, see the support page.

VAAP is an independent project and is not affiliated with or endorsed by the U.S. Department of Veterans Affairs.
