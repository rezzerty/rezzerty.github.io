CaseVac Ai

Privacy and data use

Last updated: November 11, 2026

This notice describes CaseVac Ai's public information website, private case-reference screens, manual Google Drive reader and authenticated ChatGPT MCP connection. The private app is restricted to its existing owner. The manual reader and synced MCP connection have different storage and update behavior, described below. Separate development tools and other connected apps can have different data flows.

The public website

This GitHub Pages site provides project information, support information and a link to private CaseVac Ai. It has no registration, document-upload or contact forms and contains no private claim records. Following the private-app link opens that separate service and its authentication process.

GitHub processes technical information needed to deliver and secure this site, which can include IP addresses and request logs. See GitHub's privacy statement. Emailing support sends information through your email provider and the support mailbox provider.

Information in the private app

  • Private-site identity: the hosting service supplies a site-scoped user identifier for access checks. ChatGPT sign-in and Google permission are separate.
  • Google authorization: after consent, the app receives a short-lived access token. The current reader does not request your Google password or a refresh token.
  • Document information: the server requests identifiers, names, file types, modification times, version counters, source links and plain-text exports for two configured project Google Docs. Those documents may contain personal, medical, financial or benefits information.
  • Reviewed snapshot: saved project information and source references prepared separately from a fresh Drive read are included in the private app.
  • Browser preferences and read status: the navigation screen saves record identifiers for saved and recently opened links. The reader holds current source text, dates, read results and limited refresh history for the open page session.

Google Drive permission and use

The reader requests Google's Drive read-only permission. Google's grant allows viewing and downloading files across the authorized account's Drive; it is broader than the two-document limit enforced by this app. The current reader does not offer editing, deleting, uploading, sharing changes or filing operations.

When you select Connect Google Drive, Google handles account selection and consent. The browser then sends the token over HTTPS to the private app's server. The server uses it to read the two configured documents from Google and returns their text and metadata to the private page. Further reads occur when you select Refresh sources.

Newly read text stays separate from the reviewed snapshot. It is not automatically promoted into a verified fact, legal conclusion, claim status or submission. Successful consent does not establish that a document read succeeded.

The current reader's source code does not call an AI model, advertising service or analytics service during a live refresh. Other authorized project workflows may have contributed analysis to the reviewed snapshot. If you copy information and send it to another service, that service processes what you send under its own terms and controls.

The private ChatGPT connection and synced copies

The private MCP service uses selected, previously synced project documents, evidence metadata, extracted source text and dashboard information. Its status response includes sync dates and extraction coverage. These are stored private copies, not a live Google Drive or VA query on every request. Extraction is not a completed review of a document or of the full collection.

When an authenticated ChatGPT connection calls a tool, the returned information is provided to ChatGPT for that interaction. Requests and responses may contain sensitive information from the approved sources. The ChatGPT account's applicable terms, privacy policy and data controls govern that processing. This website does not promise that connected services never store, log or retain information.

Synced source copies persist separately from the manual reader's open-page session. Disconnecting the reader, closing its page or revoking Google access does not erase existing synced copies, reviewed snapshots, chat content, historical versions or backups. Requests to review or remove operator-controlled copies must be handled through the support contact and the relevant service controls. Original Google Drive files remain separate.

Service providers and access

Google processes authorization and document requests. OpenAI Sites and its Cloudflare Workers hosting infrastructure deliver the private app and process the requests and responses needed to operate it. The app operator and authorized technical helpers may handle private source snapshots, deployment artifacts or diagnostic information for operation and support.

Application access checks, HTTPS, fixed source selection, bounded reads and escaped text rendering are protections used by the current implementation. The app returns predefined error categories instead of raw Google error messages or access tokens. These measures are not a certification or a guarantee against every security incident.

Storage and retention

  • Manual reader OAuth token: the browser keeps it in page memory and the server uses it during a read request. The application code does not intentionally save it in browser storage, a database or application logs. Disconnecting, reloading or leaving the page clears the app's token state.
  • Manual reader source text and read history: these are held in the open reader's memory and processed transiently by its server. The current reader has no persistent refresh-history database. Disconnecting or closing/reloading the page clears that session state.
  • Navigation preferences: saved and recently opened record identifiers remain in browser local storage until removed with app actions or browser site-data controls.
  • Reviewed snapshot: this remains in private source/build files and published versions even after Google access is disconnected or revoked. An authorized update is needed to change or remove it. Historical versions or backups can retain earlier copies.
  • Infrastructure records: Google and hosting providers may retain operational, security, deployment or other records under their policies and settings. Clearing a page session does not guarantee erasure from browsers, operating systems or provider infrastructure. CaseVac Ai does not promise zero retention or a fixed deletion deadline for these systems.

Your controls and privacy requests

Use Disconnect this session to clear the current reader connection and session display. To revoke the app's Google permission, use Google Account third-party connections. Disconnecting a session and revoking Google's grant are different actions. Neither deletes your Drive originals, the reviewed app snapshot or copies you saved elsewhere.

Use browser site-data controls to clear navigation preferences. For questions or requests to review, correct or remove operator-controlled information, contact lsutigerscc14@gmail.com. Identity and authority must be checked before private records are disclosed or changed. Start with a non-sensitive description; do not email passwords, access tokens, claim numbers or complete medical records.

Changes to this notice

This page will be updated as CaseVac Ai's offered features and data practices change. New data uses or permissions may require additional consent. See Support for the current connection workflow and its limits.
